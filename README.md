This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

`npm install` for packages

`vercel pull` to get the environmental variables

`npm run dev` to start the project

`yarn format` to format all .ts, .tsx, .js, .jsx files using Prettier.

NB you should be registered on vercel, and be invited to the current project.

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
